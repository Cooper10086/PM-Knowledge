# 21. iOS 开发准备与应用生命周期 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：学会使用 Xcode 建立第一个真实的 iOS 手机应用工程，看懂工程中各种关键文件的作用，并掌握 App 从启动到前后台切换时的“生命周期”函数回调逻辑。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **AppDelegate** | “在 AppDelegate 里配” | **“企业总部总机”**。掌控 App 级别的全局重大事件（如程序刚刚启动、被彻底杀死、接收到推送包通知）。整个 App 只有这一个总机。 |
| **SceneDelegate** | “写在 Scene 代理里” | **“分公司业务窗口”**。控制具体界面窗口级别的生命周期（如 App 的前后台切换、窗口聚焦等）。iOS 13 之后为了支持 iPad 多窗口分身而引入。 |
| **ViewController** | “写在 ViewController 里” | **“单个页面的大管家”**。视图控制器。每一个独立的 App 页面，都有一个 VC 在默默打理该页面的 UI 渲染和按钮逻辑。 |
| **Info.plist** | “在 plist 声明权限” | **“企业经营资质声明书”**。项目配置文件。用来向手机系统申报权限（如：使用定位、使用相机）以及锁定方向等全局静态配置。 |
| **LaunchScreen** | “换一下启动页” | **“开屏闪屏广告页”**。App 刚点开时，系统渲染出的那张静态图，用以掩盖后台复杂的加载过程。 |
| **Assets.xcassets**| “切图放进 Assets 资源束” | **“公用仓库 / 切图保管箱”**。存放 App 中所有本地图片资源、桌面图标（AppIcon）的中央文件夹。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 创建第一个 iOS App 项目配置
在 Xcode 中选择 `File -> New -> Project -> iOS -> App`。弹窗里的配置属性如下：
* **Product Name**：App 名字（如 `MyFirstApp`）。这是用户在桌面和商店里看到的名字。
* **Organization Identifier**：开发组织反向域名（如 `com.cooper`）。它与 `Product Name` 拼接成 Bundle ID 唯一身份证 `com.cooper.MyFirstApp`。
* **Interface（界面流派）**：选择 **Storyboard（故事板）**。这是一种用可视化拖拉拽拼界面的传统方案。
* **Language（开发语言）**：选择 **Swift**。

### 2.2 搞懂 iOS 13 的“Scene（场景）”窗口架构
* **iOS 13 之前**：一个 App 只能有一个窗口。
* **iOS 13 之后**：为了支持 iPad 上可以分屏同时打开两个微信，苹果把窗口管理剥离出来，叫 **Scene（场景）**。现在是：一个全局 App，可以同时管理多个活动窗口 Scene。每个 Scene 里都有自己独立的 `UIWindow` 画布，用来呈现具体的页面内容。

## 💻 3. 核心生命周期函数回调链解剖 (Lifecycle Methods)

当用户对手机进行物理操作（如切回桌面、来电、双击 Home 键）时，iOS 系统会实时通知 App 执行对应的**生命周期方法（函数）**。我们来逐个剖析这 5 个关键的“信号函数”：

### 3.1 启动与激活信号

```swift
// 1. 写在 AppDelegate.swift 中
func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    // 💡 信号：App 物理装载已完成，即将开门营业
    print("App 启动啦！")
    return true
}

// 2. 写在 SceneDelegate.swift 中
func sceneDidBecomeActive(_ scene: UIScene) {
    // 💡 信号：当前窗口已经完全亮起，用户手可以点到它，键盘可以响应了
    print("窗口获得焦点，进入活跃状态")
}
```

#### 🔍 逐个解剖：
* **`didFinishLaunchingWithOptions`**：
  * **大白话**：App “一生只触发一次”的起点。非常适合放初始化网络、注册推送通道、初始化数据库等全局配置代码。
* **`sceneDidBecomeActive`**：
  * **大白话**：App 界面彻底画完呈现在用户眼前。如果刚才视频被暂停了，在这个时刻要写下**自动恢复播放 / 重新刷新通知列表**的代码。

---

### 3.2 失去焦点与切后台信号

```swift
// 3. 写在 SceneDelegate.swift 中
func sceneWillResignActive(_ scene: UIScene) {
    // 💡 信号：界面即将失去焦点（比如突然来电、顶部滑下通知中心遮挡了 App）
    print("窗口即将失去焦点")
}

// 4. 写在 SceneDelegate.swift 中
func sceneDidEnterBackground(_ scene: UIScene) {
    // 💡 信号：用户按了 Home 键切回桌面，App 已经完全隐蔽在后台了
    print("App 已进入后台运行")
}
```

#### 🔍 逐个解剖：
* **`sceneWillResignActive`**：
  * **大白话**：警告！用户现在点击不到界面了（被来电弹窗遮住了）。此时必须写下**暂停游戏渲染、暂停音乐播放**的代码，防止用户接电话时游戏里的角色莫名死掉。
* **`sceneDidEnterBackground`**：
  * **大白话**：App 已经被冰冻挂起。此时随时可能因为手机内存不足被 iOS 系统直接“物理抹杀（强杀进程）”。为了防止用户没写完的数据丢失，**必须抓紧在这个方法里，把内存里的草稿数据写进手机硬盘存盘（落盘保存）**。
