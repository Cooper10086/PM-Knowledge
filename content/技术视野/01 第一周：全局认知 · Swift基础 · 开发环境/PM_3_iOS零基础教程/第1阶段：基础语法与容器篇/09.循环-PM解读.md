# 09. 循环 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：学会使用三种循环（while、repeat-while、for-in）来自动重复执行代码，并掌握如何用 `break` 和 `continue` 优雅控制循环的停止和跳过，避开让人头疼的“无限死循环”。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **while** | “用 while 跑逻辑” | **“只要...就一直重复”**。在执行重复任务前先核对条件，只要条件满足（`true`）就一直重复跑，条件一旦不满足（`false`）立刻退出。 |
| **repeat - while** | “写个 repeat-while” | **“先斩后奏循环”**。不管三七二十一，先执行一次大括号里的代码，然后再回头去检查条件，以决定是否进行下一次循环。 |
| **for - in** | “for 循环遍历” | **“把队列里的东西挨个拿出来过一遍”**。通常配合数组或固定范围使用。由于次数在进入循环前就已经定死，**100% 不会发生死循环**。 |
| **Infinite Loop** | “代码陷入死循环了” | **“没有出口的死胡同”**。由于判断条件永远成立（没有在循环内更新状态），导致系统在里面原地转圈，表现为 App 界面卡死、发热或耗电。 |
| **break** | “这里 break 掉” | **“紧急刹车 / 强行跳出”**。不管原计划要循环多少次，一旦执行到 break，直接当场废弃整个循环体，彻底跳走。 |
| **continue** | “这里 continue 跳过” | **“跳过这一个，继续下一个”**。中止当前这一轮的任务，不执行后面的代码，直接去判断条件开启下一轮循环。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 避坑重点：`while` 循环中的 `continue` 陷阱
* **教程说**：如果更新变量的语句（如 `index += 1`）写在 `continue` 后面，就会引发无限死循环。
* **大白话翻译**：
  * 循环到 `index == 5` 时，我们执行了 `continue`。
  * `continue` 意味着：**立刻跳过本轮剩下的代码，直接返回头部开始下一轮！**
  * 于是，排在 `continue` 后面的 `index += 1` 被跳过了。
  * 下一轮进来时，`index` 依然是 5，又碰到了 `continue`，又被跳过...
  * 结果：`index` 永远是 5，App 当场卡死。
  * **解决方案**：在执行 `continue` 前，**必须手动在它前面补上一句 `index += 1`**，强行把状态推向 6。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 经典的 while 循环计数

```swift
var index = 0 // 1. 声明计数抽屉，初始值为 0

while index < 10 { // 2. 闸门：只要 index 小于 10，就放行进入大括号
    print(index)   // 打印当前数字
    index += 1     // 3. 核心：每次干完活，计数加 1
}

print("循环完成")
```

#### 🔍 逐句解剖：
1. **`while index < 10`**：
   * `while` 会先核对条件。当 `index` 等于 0 时，`0 < 10` 成立，进入大括号打印并加 1。
   * 打印完 9 后，`index` 变成 10，回到头部判断，`10 < 10` 不成立，闸门关闭，跳出循环。
2. **`index += 1`**：
   * 复合赋值运算符。等同于 `index = index + 1`。
   * **为什么重要**：如果漏写这一句，`index` 永远是 0，永远小于 10，系统会终生打印 0，导致 **死循环**。

---

### 3.2 循环控制：break 紧急刹车

```swift
var index = 0

while index < 10 {
    if index == 5 {
        break // 💡 触发紧急刹车
    }
    print(index)
    index += 1
}
// 最终打印出: 0, 1, 2, 3, 4 (当 index 等于 5 时，直接被 break 强行终止并踢出循环)
```

---

### 3.3 repeat-while 先斩后奏循环

```swift
var index = 20

repeat {
    print(index) // 先斩：强行打印一次 20
    index += 1   // index 变成 21
} while index < 20 // 后奏：检查 21 < 20 成立吗？不成立，退出！
```

#### 🔍 逐句解剖：
* 尽管 `index` 起步就是 20，根本不满足 `< 20` 的条件。
* 但由于使用了 `repeat-while`，大括号在前面。它会**无视条件先执行一次大括号内的动作**，然后才发现条件不符，默默退场。

---

### 3.4 for-in 循环：数组与区间遍历

```swift
// 1. 遍历数组
let fruits = ["Apple", "Banana", "Orange"]
for fruit in fruits {
    print(fruit) // 自动把数组里的水果一个一个拿出来打印
}

// 2. 遍历半开区间
for i in 0..<5 {
    print(i) // 包含 0, 1, 2, 3, 4，一共循环 5 次
}

// 3. 通配符下划线（忽略循环变量）
for _ in 0..<5 {
    print("哈哈") // 纯粹为了重复打印 5 次“哈哈”，我们不在乎当前是第几次，所以用下划线占位
}
```

#### 🔍 语法细节解剖：
* **`for fruit in fruits`**：
  * `for` 后面写一个临时起的名字（如 `fruit`），`in` 后面写你要遍历的数组（如 `fruits`）。
  * **大白话**：告诉电脑：“*去把 `fruits` 柜子里的水果挨个拿出来。第 1 次拿出来的起名叫 `fruit`（值是 Apple），跑一次大括号；第 2 次拿出来也叫 `fruit`（值是 Banana）...直到数组里的东西全过一遍。*”
