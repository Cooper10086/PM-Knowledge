## 1. Swift 类型别名 (Typealias)

### 1.1 概念与定义
类型别名（Type Alias）允许开发者为 Swift 中的现有数据类型定义一个新的自定义名称。
* **关键字**：`typealias`
* **主要作用**：
  * 提高特定业务场景下的代码可读性。
  * 将复杂的底层类型（如闭包、泛型）抽象为简单易懂的名称。
  * 方便后期对数据底层类型进行统一修改。

### 1.2 语法与代码示例
```swift
// 1. 定义 UInt8 的别名 MyInt
typealias MyInt = UInt8

// 2. 使用 MyInt 声明变量
var score: MyInt = 100

// Xcode 此时将 score 推导并展示为 MyInt 类型而非 UInt8
```

## 2. Swift 枚举类型 (Enum)

### 2.1 枚举的核心概念
枚举（Enumeration）定义了一个通用类型，其中包含一组相关联的离散值。
* **与 Boolean 的差异**：Boolean 仅支持 `true` 与 `false` 两个状态，而枚举支持自定义任意多个状态。
* **与 Int 的差异**：如果使用整数代表状态（如 1=Idle, 2=Run），编译器无法拦截非法值（如 99）。枚举在**编译期**强行约束变量只能取预设的 case，从而消除了逻辑上的安全隐患。

### 2.2 枚举的基础语法与实战
```swift
// 游戏角色状态枚举定义
enum PlayerState {
    case idle
    case run
    case attack
    case die
}

// 变量声明与赋值
var currentState = PlayerState.idle

// 由于类型推导，二次赋值时可以省略枚举名称，直接使用点操作符 (.) 赋值
currentState = .run
```

### 2.3 原始值 (Raw Values) vs 关联值 (Associated Values)
Swift 的枚举功能远比传统语言强大，支持原始值与关联值两种数据存储机制。

#### 📋 原始值与关联值对比表
| 特性维度 | 原始值 (Raw Values) | 关联值 (Associated Values) |
| :--- | :--- | :--- |
| **定义时机** | **编译期**静态绑定，所有 case 必须遵循同一种类型 | **运行期**动态绑定，不同 case 可携带不同类型/个数的数据 |
| **可变性** | 固定不变。一旦定义，各 case 对应的原始值便锁死 | 可变。每次创建该 case 实例时都可以传入不同的值 |
| **支持类型** | 整数 (Int)、浮点数 (Float/Double)、字符串 (String)、字符 (Character) | 任意 Swift 类型（包含元组、自定义类/结构体等） |
| **属性获取** | 通过 `.rawValue` 获取其绑定的原始字面量 | 需要借助 `switch` 或 `if case let` 语句进行模式匹配和提取 |

#### 2.3.1 原始值代码实战
```swift
// 1. 指定原始值类型为 Int。未赋值的 case 会从前一个值自动递增（默认从 0 开始）
enum GameDifficulty: Int {
    case easy = 1
    case medium // 自动递增为 2
    case hard = 10
    case nightmare // 自动递增为 11
}

let currentDiff = GameDifficulty.medium
print(currentDiff.rawValue) // 控制台输出：2

let bossDiff = GameDifficulty.nightmare
print(bossDiff.rawValue) // 控制台输出：11
```

#### 2.3.2 关联值代码实战
```swift
// 2. 关联值定义：为特定 case 携带独特的参数信息
enum NetworkResult {
    case success(String)               // 成功时关联一个返回的 JSON 字符串
    case failure(Int, String)          // 失败时关联错误码(Int)与错误描述(String)
}

// 使用关联值赋值
var apiStatus = NetworkResult.success("{'status': 'OK'}")
apiStatus = .failure(404, "Page Not Found")
```

## 3. Swift 运算符系统

运算符是用于执行算术、比较和逻辑操作的特殊符号。

### 3.1 算术运算符 (Arithmetic Operators)
算术运算符对两个数值执行标准数学运算并返回一个计算数值。
* Swift 的除法 `/` 运算遵循**截断原则**：即 `1 / 2` 进行整数相除时，结果舍弃小数部分，直接截断为 `0`。
* 取余 `%` 运算返回整除后的余数部分。

| 运算符 | 操作 | 示例 | 结果 |
| :---: | :--- | :--- | :--- |
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2` (整数截断) |
| `%` | 取余 (模) | `5 % 2` | `1` |

---

### 3.2 赋值与复合赋值运算符 (Assignment & Compound Assignment)
* **`=`**：最基础的赋值，将右侧表达式的值拷贝写入左侧变量。
* **复合赋值**：`A += B` 等价于 `A = A + B`。
* **🚨 关键变革**：**Swift 不支持自增 `++` 与自减 `--` 运算符**。原有的 `A++` 必须使用复合赋值运算符 `A += 1` 来进行替代。

| 运算符 | 简写格式 | 等价完整表达 |
| :---: | :--- | :--- |
| `+=` | `A += B` | `A = A + B` |
| `-=` | `A -= B` | `A = A - B` |
| `*=` | `A *= B` | `A = A * B` |
| `/=` | `A /= B` | `A = A / B` |
| `%=` | `A %= B` | `A = A % B` |

---

### 3.3 比较运算符 (Comparison Operators)
比较运算符用于评估两个操作数的关系，最终返回一个 **Boolean 值 (`true` 或 `false`)**。

* **`==`**：注意必须是双等号，用于区分子等号的赋值。

| 运算符 | 操作含义 | 示例 (设 A = 5, B = 3) | 结果 |
| :---: | :--- | :--- | :---: |
| `==` | 等于 | `A == B` | `false` |
| `!=` | 不等于 | `A != B` | `true` |
| `>` | 大于 | `A > B` | `true` |
| `<` | 小于 | `A < B` | `false` |
| `>=` | 大于等于 | `A >= 5` | `true` |
| `<=` | 小于等于 | `B <= 2` | `false` |

---

### 3.4 逻辑运算符 (Logical Operators)
逻辑运算符用于连接或反转布尔条件。

```text
               ┌────── [逻辑运算符] ──────┐
               │                        │
       ┌───────┴───────┐        ┌───────┴───────┐
       ▼               ▼        ▼               ▼
   【逻辑与 &&】   【逻辑或 ||】 【逻辑非 !】  【短路机制】
   (同时真才真)    (一者真即真)   (真假取反)  (左侧已定, 右侧省去)
```

* **逻辑与 `&&` (AND)**：`A && B`。当左侧表达式为 `false` 时，右侧表达式不会被评估（短路与）。
* **逻辑或 `||` (OR)**：`A || B`。当左侧表达式为 `true` 时，右侧表达式不会被评估（短路或）。
* **逻辑非 `!` (NOT)**：`!A`。将 `true` 反转为 `false`，将 `false` 反转为 `true`。

---

### 3.5 区间运算符 (Range Operators)
区间运算符用来表达一个连续的范围，在后续 `for-in` 循环中极为重要。

* **闭区间运算符 `...`**：`a...b` 定义包含 `a` 和 `b` 在内的所有值的范围（双闭区间）。
* **半开区间运算符 `..<`**：`a..<b` 定义包含 `a` 但不包含 `b` 的范围（左闭右开区间）。

```swift
let closedRange = 1...5     // 包含：1, 2, 3, 4, 5
let halfOpenRange = 1..<5   // 包含：1, 2, 3, 4 (排除上限 5)
```
