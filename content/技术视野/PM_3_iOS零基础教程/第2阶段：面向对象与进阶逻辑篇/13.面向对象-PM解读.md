# 13. 面向对象编程 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：彻底理解面向对象编程（OOP）的核心思想，看懂类与对象的关系，并学会使用“点语法”操作对象。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **Object** | “创建个对象” | **“具体的物理/虚拟实体”**。在内存中真实存在、占用独立存储空间、能够与人交互的活生生的个体。 |
| **Class** | “定义一个类” | **“模具 / 设计图纸”**。一种抽象的概念模板，用来规定这类对象应该长什么样（属性）、能干什么（方法）。它不占用物理内存。 |
| **Instance** | “实例化一个对象” | **“照着图纸盖出物理大楼 / 倒模生产”**。实例化。根据抽象的类（图纸），在内存中真实制造出一个个独立的对象实体。 |
| **Stored Properties**| “定义类属性” | **“模具上规定的特征数据（状态）”**。定义在类图纸上的变量或常量，用来记录这个实体静态的特征。 |
| **Methods** | “调用类方法” | **“模具上规定的特定功能（行为）”**。定义在类图纸上的函数，描述这个实体可以执行哪些动作。 |
| **Dot Syntax** | “用点语法访问” | **“寻找定位符”**。在代码中使用点操作符 `.`，来读写一个对象的内部属性，或命令对象执行某个动作（方法）。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 搞懂“类 (Class)”与“对象 (Object)”的倒模关系
* **类**：就像是一个**饼干模具**（或者汽车设计图纸）。模具本身是不能吃的，它只是定义了饼干会有什么花纹、什么尺寸。
* **对象 / 实例**：是用这个模具烘焙出来的**一块块具体的饼干**。它们是真实吃得着的，每一块都可以涂上不同的巧克力酱或奶油（各自拥有独立的内存数据），且它们之间互不影响。

---

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 声明“汽车”类（画好模具图纸）

```swift
class Car {
    // 1. 成员属性 (描述静态状态)
    var brand: String = "未命名品牌" // 品牌
    var color: String = "白色"     // 颜色
    var speed: Double = 0.0        // 当前时速
    
    // 2. 成员方法 (描述能执行的操作)
    func startEngine() {
        print("\(color)的\(brand)引擎已启动！")
    }
    
    func accelerate(to targetSpeed: Double) {
        speed = targetSpeed
        print("汽车加速至 \(speed) km/h。")
    }
}
```

#### 🔍 语法细节解剖：
* **`class Car`**：
  * **`class` 关键字**：告诉电脑，我要开始定义一张名为 `Car` 的汽车类图纸了。
* **`var brand: String = "未命名品牌"`**：
  * **注意**：Swift 的强类型安全机制规定：类里面定义的所有普通变量，**必须在定义时给出一个初始默认值**（如这里的 `"白色"`、`0.0`），或者在后面要学的 `init` 构造器里赋值，否则编译器会直接报错。
* **`func startEngine()`**：
  * 定义在类大括号内部的函数，在面向对象里被称为**“方法（Method）”**。它代表汽车实体能被触发的动作。

---

### 3.2 实例化对象与属性访问（倒模生产与操作）

```swift
// 1. 实例化：照着 Car 图纸，制造两辆相互独立的物理车辆
let myCar = Car()
let dreamCar = Car()

// 2. 使用点语法，改写 myCar 独立的属性值
myCar.brand = "Tesla Model 3"
myCar.color = "红色"

// 3. 呼叫 myCar 执行动作
myCar.startEngine() // 打印输出: 红色的Tesla Model 3引擎已启动！

// 4. dreamCar 保持出厂默认设置，完全不受 myCar 的影响
dreamCar.startEngine() // 打印输出: 白色的未命名品牌引擎已启动！
```

#### 🔍 语法细节解剖：
* **`Car()`**：
  * 类名后面紧跟一对圆括号。
  * **大白话**：触发实例化动作。命令工厂：“*立刻照着 Car 的图纸，在堆内存里造出一辆真实的汽车实体。*” 然后用 `let` 锁死箱子 `myCar` 装载这个实体的内存地址。
* **`myCar.brand = "Tesla Model 3"`**：
  * 使用点语法 **`.`**。
  * **大白话**：定位到 `myCar` 这辆物理车身上的 `brand` 属性抽屉，强行把里面的默认文本改为 `"Tesla Model 3"`。
* **`myCar.startEngine()`**：
  * **大白话**：拍一下 `myCar` 车身上的“引擎启动”按钮，命令 `myCar` 去跑它图纸上规定好的 `startEngine` 代码逻辑。
