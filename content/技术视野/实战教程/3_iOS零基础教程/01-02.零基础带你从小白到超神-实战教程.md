# 【iOS教程】零基础带你从小白到超神 - 实战教程

> **学习导读**：本教程基于《【iOS教程】零基础带你从小白到超神》第 1、2 集核心知识整理。将帮助零基础的学员建立清晰的 iOS 开发环境认知，掌握开发工具 Xcode 的基础工作流，并精通 Swift 编程语言中最核心的基石概念——常量、变量与注释的运用。

## 1. iOS 开发环境与生态概述

### 1.1 什么是 iOS 开发？
* **操作系统核心**：iOS 是苹果公司专为 iPhone、iPad、Apple Watch (WatchOS)、Apple TV (tvOS) 以及 Mac (macOS) 生态圈移动端打造的操作系统。
* **开发设备限制**：iOS 应用程序开发具有硬件强绑定性，必须在 **macOS 操作系统（即 Mac 电脑）** 环境下进行原生编译与构建。

### 1.2 主流开发语言：Objective-C vs Swift
Swift 与 Objective-C (OC) 是目前苹果官方支持的两大核心开发语言。

#### 🔄 语言对比表
| 特性维度     | Objective-C (OC)        | Swift                      |
| :------- | :---------------------- | :------------------------- |
| **诞生时间** | 1984 年 (历史悠久)           | 2014 年 6 月 (WWDC 发布)       |
| **语法风格** | 繁复、基于 Smalltalk 的消息传递机制 | 现代、简洁、类 Python/Kotlin，安全性高 |
| **应用场景** | 公司老旧项目维护、底层 C/C++ 交互    | 全新项目开发、现代 App 逻辑编写         |
| **发展态势** | 逐渐被替代，进入存量维护期           | 主流首选，官方主力维护与更新             |
| **混编支持** | 支持与 Swift 混编            | 支持与 OC 混编，相互调用极为便利         |

## 2. Xcode 核心工作流

### 2.1 软件获取
* 苹果官方唯一的集成开发环境 (IDE) 为 **Xcode**。
* **获取途径**：直接在 macOS 系统的 **App Store** 中搜索 `Xcode` 下载并获取。

### 2.2 创建 Command Line Tool (命令行工具) 项目
为方便学习 Swift 核心语法，初期建议从最轻量级的 macOS 命令行工程入手：
1. 打开 Xcode -> 选择 `Create a new Xcode project`。
2. 在顶部平台模板栏选择 `macOS`，并在 Application 类别中选择 `Command Line Tool`。
3. 配置核心项目属性：
   * **Product Name**：项目名称（如 `class1`）。
   * **Team**：开发者团队（未申请账号则选 `None`）。
   * **Organization Identifier**：反向域名格式的组织标识（如 `com.feiyu`）。
   * **Bundle Identifier**：由 `Organization Identifier` + `Product Name` 自动生成（如 `com.feiyu.class1`）。
     > [!IMPORTANT]
     > Bundle Identifier 是真机调试与 App Store 上架时的唯一 ID。如果两个应用的 Bundle ID 相同，在同一台设备上安装时，后安装的会强行覆盖前一个应用。
   * **Language**：选择 **Swift**。

### 2.3 Xcode 界面布局

```text
┌──────────────────────────────────────────────────────────────┐
│  ▶ [Run]       [class1 > My Mac]                             │ Xcode 头部状态栏
├───────────────┬──────────────────────────────────────────────┤
│ 📂 Navigator  │ 📝 main.swift (Code Editor)                  │
│  ├─ class1    │                                              │
│  │   ├─ main  │  import Foundation                           │ 中部：代码编辑器
│  │   └─ spec  │  print("Hello, World!")                      │
│  │            │                                              │
│  │            │                                              │
│  │            │                                              │
│               ├──────────────────────────────────────────────┤
│               │ 💻 Debug Area (Console Output)               │
│               │  Hello, World!                               │ 底部：控制台输出
│               │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

* **左侧导航栏 (Navigator)**：管理项目中的所有源文件和资源文件（核心入口为 `main.swift`）。
* **中间编辑器 (Editor)**：核心代码编辑区，双击左侧文件后在此处展现。
* **右侧属性栏 (Inspector)**：控制 UI 控件及工程的高级配置（命令行模式下无需理会）。
* **底部调试控制台 (Console)**：通过右下角按钮控制显示，右侧输出区负责展示 `print()` 打印的结果。
* **运行快捷键**：`Cmd + R` 执行编译运行，`Cmd + S` 进行文件保存。

## 3. Swift 语法精要：注释、变量与常量

### 3.1 注释 (Comments)
注释是仅供开发者阅读的备注说明，在编译执行时会被编译器完全忽略。

#### 3.1.1 单行注释
使用双斜线 `//` 引导，作用范围仅限当前行。
```swift
// 这是一行单行注释
let rate = 0.05
```

#### 3.1.2 多行注释
使用 `/*` 开始，`*/` 结束，其间所有内容均被判定为注释，支持跨行编写。
```swift
/*
 这是一个多行注释的示例
 可用于撰写详细的技术方案、需求说明
 或是对复杂算法步骤进行拆解
*/
```

---

### 3.2 量 (Quantity) 的基本概念
在 Swift 语言中，可以将“量”（即数据存储单元）形象地理解为**存放数据的盒子**。
* **核心限制**：在同一时间，一个盒子内只能存放单个数据（可为数值、字符串、数据对象等），不可以放入多个独立数据。
* **分类**：按照盒子是否可重新存入数据，分为 **常量** 与 **变量**。

---

### 3.3 常量 (Constants) 与 变量 (Variables) 深度对比

#### 📋 常量与变量对比表
| 特性维度 | 常量 (Constant) | 变量 (Variable) |
| :--- | :--- | :--- |
| **关键字** | `let` | `var` |
| **可变性** | **不可改变**（写入初始值后，盖子将被完全锁死） | **可以改变**（可以随时开盖，取出旧值，装入新值） |
| **声明场景** | 适用于配置项、不会发生改变的量（如圆周率、重力加速度、唯一密钥） | 适用于需要在程序运行中不断计算或改变的量（如积分、计数器、用户状态） |
| **报错情形** | 尝试重新赋值会导致编译报错 `Cannot assign to value` | 可进行多次赋值操作，合法运行 |

#### 3.3.1 命名规范与限制
1. **合法字符**：推荐使用 **英文字母**、**数字** 以及 **下划线 `_`** 的组合。
2. **开头限制**：**数字绝对不能作为命名的开头**。
   * `let a1 = 10` (合法)
   * `let 1a = 10` (不合法，编译报错)
3. **中文命名**：Swift 底层支持 Unicode 命名，即 `let 盒子 = 10` 能够合法编译。但在真实的企业开发中，**禁止使用中文拼音或汉字命名**，以免引发跨系统协作兼容性问题。

#### 3.3.2 变量与常量代码实战
```swift
import Foundation

// ==================== 1. 常量的声明与限制 ====================
let speedLimit = 120 // 声明一个常量，值为 120
print(speedLimit)

// speedLimit = 100 
// ❌ 编译报错：Cannot assign to value: 'speedLimit' is a 'let' constant

// ==================== 2. 变量的声明与修改 ====================
var currentScore = 10 // 声明一个变量，初始值为 10
print(currentScore)

currentScore = 25 // 修改变量的值。注意：已被声明过的变量，二次赋值时绝对不要重写 var 关键字
print(currentScore)

// ==================== 3. 量与量之间的值拷贝 ====================
let baseValue = 50
var calculatedValue = 0

calculatedValue = baseValue // 将常量 baseValue 中的值拷贝并赋值给变量 calculatedValue
print(calculatedValue) // 控制台输出：50
```

> [!TIP]
> **关于分号 `;`**：在 Swift 中，每行代码末尾的分号 `;` 是可选的。通常情况下推荐省略分号，这能让代码看起来更加清爽与现代。只有当你想在同一行编写多条独立的语句时，才需要使用分号进行隔开（不推荐此类编写习惯）。
