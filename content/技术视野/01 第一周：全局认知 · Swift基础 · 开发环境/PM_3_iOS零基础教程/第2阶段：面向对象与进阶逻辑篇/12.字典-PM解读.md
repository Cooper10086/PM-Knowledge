## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **Dictionary** | “用字典存这个映射” | **“姓名标签柜”**。使用唯一的键（Key）来映射存放值（Value）的无序集合。它不关心存取顺序，只要你报出标签名，就能瞬间取出里面的物品。 |
| **Key** | “用这个作为 Key” | **“储物柜上贴的唯一姓名贴”**。在同一个字典里，Key 必须是独一无二的，绝对不准重复。 |

| **Nil Coalescing (`??`)** | “用双问号给个默认值” | **“空值合并运算符 / 备用保底垫”**。如果双问号左边查出来的值是 `nil`，就直接使用双问号右边的默认值，防闪退利器。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 字典与数组的物理结构差异
* **数组 (Array)**：是一条笔直的高速公路，格子紧挨着，靠格子号 `0, 1, 2` 访问。要找特定数据，如果不知道号，只能排队挨个找，速度慢。
* **字典 (Dictionary)**：是一个大蜂巢。每个格子挂一个名字牌（Key）。电脑存了“位置哈希表”，只要你报出名字，电脑瞬间就能定位到具体格子，查找速度快到飞起。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 声明并创建一个字典

```swift
// 1. 显式声明 [键类型 : 值类型] 字典并初始化
var emptyDict: [String: Int] = [:] 

// 2. 字面量创建（类型推断为 [String: Int]）
var scores = ["Chinese": 95, "Math": 98, "English": 90]
```

#### 🔍 语法细节解剖：
* **`[String: Int]`**：
  * 方括号里冒号隔开两个类型。
  * **大白话**：规定这个字典的键（Key）必须是 `String` 文字，值（Value）必须是 `Int` 整数。
* **`[:]`**：
  * **大白话**：代表一个**空字典**字面量。

---

### 3.2 字典的 CRUD (增删改查) 与可选值安全

```swift
// ==================== 1. 读取 (查) ====================
// 💡 警告：scores["Math"] 返回的是 Int? 可选类型！因为可能有找不到的风险。

// 做法 A：使用可选绑定安全解包
if let mathScore = scores["Math"] {
    print("数学分: \(mathScore)")
}

// 做法 B：使用 ?? 提供兜底值
let historyScore = scores["History"] ?? 0 // 如果找不到 History 键，就返回 0

// ==================== 2. 添加与修改 (增/改) ====================
scores["Science"] = 88  // 键 Science 不存在，执行【添加】：新增 Science 格子并装入 88
scores["Chinese"] = 100 // 键 Chinese 已存在，执行【修改】：把原本的 95 擦掉改写成 100

// ==================== 3. 删除 (删) ====================
scores["English"] = nil // 直接把 English 的格子清空设为 nil，系统会自动移除这一格
```

#### 🔍 语法细节解剖：
* **`scores["Math"]`**：
  * 方括号里写具体 Key。
  * **为什么返回可选值**：因为你输入 `"Math"`，系统去翻标签，但系统不敢保证字典里 100% 录入了数学成绩。如果没录入，系统会给你返回 `nil`。所以，**任何从字典里拿出来的数据，在 Swift 里天生都是加了“可选值盲盒”外壳的**（如 `Int?`）。
* **`scores["History"] ?? 0`**：
  * **双问号 `??`**。
  * **大白话**：告诉电脑：“*去 scores 柜子找 History 成绩。如果找到了就拿出来，如果找不到（返回 nil 摸空了），就直接给我返回数字 0 备用。*”

---

### 3.3 字典的遍历 (Iteration)

```swift
// 同时遍历键与值，每一项以 (key, value) 的元组解构出来
for (subject, score) in scores {
    print("科目: \(subject), 分数: \(score)")
}
```

#### 🔍 逐句解剖：
* **`for (subject, score) in scores`**：
  * **`for (键临时变量, 值临时变量) in 字典`**。
  * **大白话**：把 `scores` 柜子里的键值对一个一个挑出来。每一对拿出来时，把名字牌塞进 `subject` 盒子，把里面的分数塞进 `score` 盒子，然后执行一次打印。
