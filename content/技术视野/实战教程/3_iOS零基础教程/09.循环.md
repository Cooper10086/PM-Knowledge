## 第一部分：原始转写整理（按章节排版）

### 1. 循环的目的与控制方式
好，那么这节课我们来说一下循环。
循环主要是有两个目的。第一个，我们可以通过一个条件表达式来控制循环，或者你可以把它理解为通过一个布尔值来控制是否要进行循环。循环在生活当中就是重复地去干某些事情，比如在《奇异博士》里面，主角最后开启了一个循环，每一次都会重新去找 Boss 商谈一些事情。
在 Swift 中，循环我们可以通过一个布尔值来进行控制，这个语法就是 `while` 循环。

### 2. While 循环与死循环
`while` 循环是通过布尔值来控制的。它的写法非常简单，不需要用圆括号包裹条件，`while` 后面直接跟一个条件（通常是一个条件表达式），然后在大括号里面写代码块。
这个写法和 `if` 语句看起来非常像，区别在于：`if` 语句条件成立后执行一次就退出来了，而 `while` 语句在代码块执行完成以后，不会跳出去，它会再次回到头部重新判断条件。如果条件还成立，就继续执行代码块，如此往复。
如果条件一直成立，就会导致死循环，下面的代码就无法执行了。为了避免死循环，我们需要在循环体内部通过各种方法去修改循环变量的值。例如，我们定义一个 `index` 变量：
```swift
var index = 0
while index < 10 {
    print(index)
    index += 1
}
print("循环完成")
```
这段代码最开始进来时 `index` 等于 0，满足 `0 < 10` 的条件，执行打印并自增 1，然后依次循环，直到 `index` 变为 10 时条件不成立，跳出循环，最后打印“循环完成”。这轮循环一共从 0 到 9 执行了 10 次。

### 3. 循环控制：break 与 continue
在循环体内部，我们也可以手动控制循环的结束或跳过：
- **break**：表示跳出离它最近的这一层循环。
  如果在循环过程中，当 `index` 等于 5 时跳出循环：
  ```swift
  var index = 0
  while index < 10 {
      if index == 5 {
          break
      }
      print(index)
      index += 1
  }
  print("循环完成")
  ```
  运行后，当 `index` 为 5 时执行了 `break`，整个循环立刻结束，因此只打印了 `0, 1, 2, 3, 4`。
- **continue**：表示结束当前的这一轮循环，直接进入下一轮循环。
  需要特别注意的是，在 `while` 循环中使用 `continue` 时，如果我们的更新变量语句（如 `index += 1`）写在 `continue` 后面，就会因为被跳过执行而导致 `index` 永远停留在满足 `continue` 条件的值上，从而引发死循环。所以我们必须在 `continue` 之前手动改变循环变量：
  ```swift
  var index = 0
  while index < 10 {
      if index == 5 {
          index += 1 // 必须先让 index 递增，否则 index 永远是 5，会导致死循环
          continue
      }
      print(index)
      index += 1
  }
  ```
  这样运行后，打印结果会跳过 5，输出 `0, 1, 2, 3, 4, 6, 7, 8, 9`。

### 4. repeat-while 循环
与 `while` 循环非常相似的还有 `repeat-while` 循环（在其他语言中常被称为 `do-while`）。
它们的区别在于：
- `while` 循环是先判断条件再执行代码块。如果第一次判断条件就不成立，循环体一次都不会执行。
- `repeat-while` 的条件是写在后面的。当代码执行到这里时，它一定会先执行一次代码块，然后再判断条件是否成立，以决定是否进行下一次循环。
```swift
var index = 20
repeat {
    print(index)
    index += 1
} while index < 20
```
虽然 `repeat-while` 有这样的特征，但在实际开发中用得很少，绝大多数情况下我们都是使用标准的 `while` 循环，这主要取决于开发者的习惯。

### 5. for-in 循环
第二类循环是 `for-in` 循环，主要用于遍历数组或遍历范围。
- **遍历数组**：
  在前面我们学过数组，如果有一个包含多个数字的数组 `numbers`：
  ```swift
  let numbers = [3, 4, 5, 6]
  for n in numbers {
      print(n)
  }
  ```
  这里的 `n` 是我们随便命名的一个临时变量，系统会自动将它推断为数组元素的类型（在这个例子中是 `Int`），不需要使用 `var` 或 `let` 去声明。数组有几项，大括号里面的代码块就会执行几次。每一轮执行时，它会依次把数组里的元素赋值给临时变量 `n`，因此上面的代码可以非常方便地把数组的 3, 4, 5, 6 依次打印出来。
- **遍历范围**：
  我们之前学过范围运算符。
  - 闭区间范围 `0...5` 表示包含 5 的范围（即 0 到 5，共循环 6 次）：
    ```swift
    for i in 0...5 {
        print(i)
    }
    ```
  - 半开区间范围 `0..<5` 表示不包含 5 的范围（即 0 到 4，共循环 5 次）：
    ```swift
    for i in 0..<5 {
        print(i)
    }
    ```
- **忽略临时变量（通配符 `_`）**：
  有时候我们只需要让代码循环执行特定的次数，在循环体内部并不需要用到临时变量。如果不使用变量，系统会报一个未使用的警告。此时我们可以使用下划线 `_` 来代替临时变量：
  ```swift
  for _ in 0..<5 {
      print("哈哈")
  }
  ```
  这样系统就知道我们不需要临时变量，只会执行 5 次打印“哈哈”。
在 iOS 开发中，比如新闻列表、游戏道具栏等，绝大多数应用都是用数组来保存列表数据的。因此，我们会非常高频地使用 `for-in` 循环去遍历数组。

## 第二部分：深度实战教程（逻辑归纳与总结）

本章重点讲解了 Swift 语言中的循环控制结构。循环是程序控制流的基础，主要包括条件循环（`while` / `repeat-while`）和集合/区间遍历（`for-in`）。

### 1. Swift 循环结构概览

| 循环类型 | 语法特征 | 执行特点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **while** | `while condition { ... }` | 先判断条件，再执行。可能执行 0 次或多次。 | 循环次数不确定，依赖某个外部条件的改变。 |
| **repeat-while** | `repeat { ... } while condition` | 先执行一次，再判断条件。至少执行 1 次。 | 需要先执行一次业务逻辑，再根据执行结果决定是否继续。 |
| **for-in** | `for item in sequence { ... }` | 顺序遍历集合（数组、字典）或区间（Range）的每个元素。 | 数组遍历、固定次数区间循环。iOS 开发中最高频的循环方式。 |

### 2. 核心语法与代码示例

#### 2.1 条件循环
在条件循环中，必须确保循环条件在未来的某个时间点会变为 `false`，或者在内部使用 `break` 跳出，否则将导致死循环。

```swift
// 1. 标准 while 循环
var index = 0
while index < 5 {
    print("while index: \(index)")
    index += 1
}

// 2. 标准 repeat-while 循环
var repeatIndex = 0
repeat {
    print("repeat index: \(repeatIndex)")
    repeatIndex += 1
} while repeatIndex < 5
```

#### 2.2 序列与区间遍历 (`for-in`)
`for-in` 是 Swift 中最常用的循环，配合区间运算符或集合使用。

```swift
// 1. 遍历区间 (闭区间 ... 与 半开区间 ..<)
for i in 1...3 {
    print("闭区间: \(i)") // 输出 1, 2, 3
}

for i in 1..<3 {
    print("半开区间: \(i)") // 输出 1, 2
}

// 2. 遍历数组
let fruits = ["Apple", "Banana", "Orange"]
for fruit in fruits {
    print("水果: \(fruit)")
}

// 3. 通配符循环（忽略循环变量）
for _ in 1...3 {
    print("执行重复任务，无需关注变量")
}
```

### 3. 循环控制与避坑指南

#### 3.1 `break` 与 `continue` 机制对比
- `break` 用于立即跳出并终止当前的整个循环体。
- `continue` 用于结束当前的这一次迭代，直接开始下一次的循环条件评估。

```swift
// break 示例：在 i 等于 5 时终止循环
for i in 1...10 {
    if i == 5 { break }
    print(i) // 输出 1, 2, 3, 4
}

// continue 示例：在 i 等于 3 时跳过打印，进入下一次循环
for i in 1...5 {
    if i == 3 { continue }
    print(i) // 输出 1, 2, 4, 5
}
```

#### 3.2 避坑：`while` 循环中的 `continue` 陷阱
> [!WARNING]
> 在 `while` 循环中使用 `continue` 时，如果改变迭代状态的代码（例如 `index += 1`）位于 `continue` 之后，跳过执行将导致变量状态不再发生改变，从而引发无限死循环。

**错误代码示范：**
```swift
var i = 0
while i < 10 {
    if i == 5 {
        continue // 错误！i 永远等于 5，在此处无限循环
    }
    print(i)
    i += 1
}
```

**正确解决方案：**
在执行 `continue` 前，手动更新迭代变量的值：
```swift
var i = 0
while i < 10 {
    if i == 5 {
        i += 1 // 提前更新状态，防止死循环
        continue 
    }
    print(i)
    i += 1
}
```
