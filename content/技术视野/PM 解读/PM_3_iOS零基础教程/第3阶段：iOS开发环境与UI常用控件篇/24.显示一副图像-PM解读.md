# 24. 图像展示与视网膜倍图适配 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：掌握 UIImageView 图片容器的职责分工与加载方式，学会使用内置 API 实现简易的序列帧动画，并理解 iOS 逻辑点与物理像素的关系及 `@2x / @3x` 自动无损适配机制。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **`UIImageView`** | “拖个 Image 视图框” | **“物理相框”**。在界面上划定一块矩形区域，用来把照片挂载展示在屏幕上。只负责框架布局和层级，不含图片内容。 |
| **`UIImage`** | “创建个 image 对象” | **“相框里的照片纸”**。代表纯粹的图片二进制数据文件（JPG/PNG）。负责把图片读进内存并进行解析。 |
| **Point (pt)** | “以逻辑点为单位进行布局” | **“逻辑物理尺标”**。我们在开发和画原型图（如 Sketch、蓝湖）时用的逻辑长度单位。在所有不同清晰度的 iPhone 上看起来尺寸基本一致。 |
| **Pixel (px)** | “屏幕物理像素” | **“手机屏幕上的物理发光点网格”**。发光点越密，屏幕倍率越高，画面越细腻。 |
| **Scale** | “获取设备的 Scale 倍率” | **“一格逻辑点对应几个发光点”**。转换率。公式为：$\text{px} = \text{pt} \times \text{Scale}$。 |
| **Frame Animation** | “ImageView 跑个序列帧” | **“小人书连环画”**。给相框塞入一组按顺序排好的图片数组，设定好循环速度，让它像播放动画片一样跑起来。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 搞懂 `@2x` 和 `@3x` 的智能加载策略
* **设计切图**：设计师将同一个图标切出两种规格：`pic@2x.png` ($200 \times 200 \text{ px}$) 和 `pic@3x.png` ($300 \times 300 \text{ px}$)。
* **Assets.xcassets 资源管理**：研发将这两张图拖入 Xcode 的 Assets 资源束中。
* **按需自动加载**：代码加载时只需写 `UIImage(named: "pic")`。当 App 运行在 iPhone 8 (Scale=2) 上时，系统会自动去读 `pic@2x.png`；运行在 iPhone 13 Pro (Scale=3) 上时，自动读取 `pic@3x.png`。**这完美实现了按物理网格对齐，图标绝对不糊**。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 载入并显示单张本地图片

```swift
// 1. 创建 UIImageView 物理相框，尺寸定为 100 * 100 pt
let logoView = UIImageView(frame: CGRect(x: 50, y: 120, width: 100, height: 100))

// 2. 装载图片实体。
// UIImage(named:) 是可选初始化器，若资源名字写错或文件缺失，会返回 nil。
// 这里的感叹号 ! 代表强拆，我们确信图片存在，强行拆开包装盒。
let logoImage = UIImage(named: "avatar")! 

// 3. 把照片塞入相框中
logoView.image = logoImage

// 4. 挂载到主画布上
self.view.addSubview(logoView)
```

### 3.2 序列帧动画控制 (Frame-by-Frame)

```swift
let animView = UIImageView(frame: CGRect(x: 100, y: 200, width: 80, height: 120))
self.view.addSubview(animView)

// 1. 组装小人书的 4 页画面（UIImage 数组）
let frameList = [
    UIImage(named: "walk_1")!,
    UIImage(named: "walk_2")!,
    UIImage(named: "walk_3")!,
    UIImage(named: "walk_4")!
]

// 2. 将照片数组塞入相框的 animationImages 属性中
animView.animationImages = frameList

// 3. 配置播放参数
animView.animationDuration = 0.8  // 翻完这 4 页书总共需要 0.8 秒
animView.animationRepeatCount = 0 // 循环播放次数，0 代表不限次数，无限循环

// 4. 启动翻页动画
animView.startAnimating()

// 停止播放 API: animView.stopAnimating()
```

#### 🔍 语法细节解剖：
* **`animView.animationImages = frameList`**：
  * **`animationImages`** 属性。
  * **大白话**：专门用来接收一组 `UIImage` 的数组。塞入后，相框就进入了“动画播放预备状态”。
* **`animView.animationRepeatCount = 0`**：
  * **注意**：这里的数字 0 在 iOS 动画控制中是一个**特殊魔法数字**，代表“不要停止，无限循环循环播放下去”。
* **`animView.startAnimating()`**：
  * **大白话**：下达开播命令，光标开始自动按帧速播放。
