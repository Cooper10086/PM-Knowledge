# 14. 属性与计算属性 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：学会看懂 Swift 代码中如何使用 `self` 指针防止变量名打架，并掌握计算属性（Computed Properties）的读写过滤安全机制。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **`self`** | “加个 self 区分下” | **“我 / 我的”**。一个动态指针。指代当前正在执行该动作的这个实体自己。主要用来区分类本身的属性和方法里传进来的同名变量。 |
| **Stored Property** | “声明个存储属性” | **“实体储物抽屉”**。实打实在内存中开辟空间，用来存储具体原始数据的普通变量。 |
| **Computed Property**| “写个计算属性” | **“带安全卫兵的虚拟假窗”**。本身不占用任何内存空间。外界读取它时触发 `get` 拦截，修改它时触发 `set` 拦截，通过逻辑间接控制底层存储属性。 |
| **`get`** | “在 get 里返回” | **“读取过滤关卡”**。外界读取这个属性时自动触发的代码块。必须使用 `return` 返回一个最终算出来的数据。 |
| **`set` (newValue)** | “在 set 里加判断” | **“写入校验关卡”**。外界尝试修改这个属性的值时自动触发。可以用 `newValue`（传入的新值）做大小限制和数据清洗。 |
| **Read-Only Property**| “写成只读计算属性” | **“动态液晶液晶显示屏”**。只有 `get` 没有 `set` 的计算属性。值完全随着别的数据联动计算得出，外界绝对无法强行写入修改它。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 为什么要使用“计算属性”来保护数据？
* **教程说**：直接暴露成员变量允许外界任意读写可能会造成数据污染，通过 `get` 和 `set` 拦截器可以建立安全屏障。
* **大白话翻译**：如果年龄 `age` 是公开可写的抽屉。别的研发在别的文件里写一句 `p.age = -99`，系统也会无脑接受。这就会导致 App 界面上显示出“年龄：-99岁”的荒谬 Bug。
* 我们把真实的抽屉藏起来（用 `private`），在门外装一个名为大写 `Age` 的计算属性假窗户。别人往假窗户里倒数据 `-99` 时，我们用 `set` 拦截并过滤清洗成 `0`，从而**在代码底层彻底杜绝了异常数据的产生**。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 成员命名冲突与 `self` 指针

```swift
class Person {
    var name: String = "婴儿" // 成员变量 (类属性)
    
    // 参数名也叫 name 
    func updateName(name: String) {
        self.name = name // 💡 用 self. 指示自己
    }
}
```

#### 🔍 逐句解剖：
* **`self.name = name`**：
  * **等号左边的 `self.name`**：代表“**我（这个人实体）自己身上定义的那个** `name` 属性”。
  * **等号右边的 `name`**：代表“外面调用这个方法时，传进来的那个临时变量参数 `name`”。
  * **大白话**：把传进来的名字，放进我自己的名字抽屉里。

---

### 3.2 计算属性 (Computed Properties) 读写拦截

```swift
class Person {
    // 1. private 声明私有存储抽屉，严禁外部直接开箱读写
    private var age: Int = 0 
    
    // 2. 声明同名的大写 Age 计算属性作为对外安全接口
    var Age: Int {
        get {
            return self.age // 外部读取时，老老实实送出真实的 age
        }
        set(newValue) { // 外部执行 p.Age = 新值时触发，newValue 代表新值
            if newValue > 150 {
                self.age = 150 // 数据清洗：超标了，强行压到 150
            } else if newValue < 0 {
                self.age = 0   // 数据清洗：负数了，强行归零
            } else {
                self.age = newValue // 合理值，正常装入抽屉
            }
        }
    }
}
```

### 3.3 只读计算属性 (Read-Only Computed Properties)

```swift
class Rectangle {
    var width: Double = 0.0
    var height: Double = 0.0
    
    // 💡 声明只读计算属性 area（面积）- 省略了 get 和大括号
    var area: Double {
        return width * height 
    }
}

let rect = Rectangle()
rect.width = 10.0
rect.height = 5.0
print(rect.area) // 自动计算输出: 50.0
// rect.area = 100.0 // ❌ 编译直接报错！只读属性绝对不准被赋值
```

#### 🔍 逐句解剖：
* **`var area: Double { return ... }`**：
  * 只读属性**没有 `set` 块**，所以可以用极简的大括号加 `return` 表达式来缩写。
  * **大白话**：`area` 是个动态计算器。你只要查我，我就去拿现在的宽度乘以高度算个结果给你。你休想手动改写我的值。
