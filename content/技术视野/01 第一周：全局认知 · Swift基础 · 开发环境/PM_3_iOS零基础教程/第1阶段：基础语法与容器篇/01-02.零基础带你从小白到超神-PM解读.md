# 01-02. 零基础带你从小白到超神 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：学会搭建 iOS 开发环境，了解开发工具 Xcode 的基础布局，并看懂 Swift 代码中最核心的“常量、变量与注释”是如何编写和运行的。

---

## 📖 1. 本章名词字典 (Glossary for PM)

在开始阅读教程前，请先熟悉以下名词，它们是看懂后续步骤的“翻译钥匙”：

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **macOS** | “苹果系统 / Mac环境” | 苹果电脑专用的操作系统。iOS App 的“出厂流水线”被苹果锁死在 macOS 内部，因此必须用 Mac 电脑开发。 |
| **Objective-C (OC)** | “老项目用的 OC” | 苹果 10 年前的主流开发语言。语法繁复，像天书；现在已进入维护期，新 App 极少采用。 |
| **Swift** | “用 Swift 写” | 苹果在 2014 年发布的新一代开发语言。现代、简洁，像英语一样好读，是目前开发 iOS 的绝对主力。 |
| **Xcode** | “打开 Xcode” | 苹果官方唯一的 **“全能开发软件 (IDE)”**。集成了代码编辑器、界面画板、模拟器和打包工具。 |
| **Command Line Tool** | “创建一个命令行项目” | **“极简小黑窗程序”**。不带任何手机界面，专门用来在控制台打印纯文字的轻量级程序，最适合初学者练语法。 |
| **Bundle Identifier** | “包名 / Bundle ID” | **“App 的身份证号”**。全球唯一。两个 App 如果身份证号相同，在同一台手机上安装时，后者会强行顶替覆盖前者。 |
| **Console** | “看控制台输出” | **“测试黑板报”**。Xcode 底部的一个纯文字窗口。代码里的 `print` 命令会将结果打印在这里，用来检查程序运行是否正确。 |
| **import Foundation** | “引入基础库” | **“给程序装上最基础的工具箱”**。导入苹果底层最核心的通用工具包（提供处理文字、数字、时间等基本功能）。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 准备工作：获取 Xcode
* **教程说**：在 App Store 中搜索 `Xcode` 下载并获取。
* **大白话翻译**：Xcode 是免费的，但体积极大（通常超过 10GB），下载和安装需要较长时间。它是您编写和运行 iOS 代码的“大本营”。

### 2.2 创建您的第一个 Swift 练习项目
在 Xcode 中创建项目时，会有以下配置弹窗。让我们看看每一个格子里填的是什么：

1. **Product Name（产品名称）**：填入您的项目名字（如 `class1`）。这会成为您测试程序的名字。
2. **Organization Identifier（组织标识符）**：通常用“反向域名”的形式填写（如 `com.feiyu`）。
3. **Bundle Identifier（App 身份证号）**：系统会自动将上面两个格子拼起来，变成 `com.feiyu.class1`。**请记住这个 ID，以后上架和接入微信分享时全靠它。**
4. **Language（开发语言）**：选择 **Swift**。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

在项目左侧导航栏双击打开 `main.swift` 文件，您会看到如下代码。我们来逐句拆解：

### 3.1 初始的 "Hello, World!"

```swift
import Foundation // 1. 搬出“基础工具箱”
print("Hello, World!") // 2. 在底部黑板报上打印出一行字
```

#### 🔍 逐句解剖：
1. **`import Foundation`**：
   * `import` 意为“导入”。
   * `Foundation` 意为“基础”。
   * **大白话**：告诉电脑，我要开始写最基础的程序了，请把苹果底层的“字词句计算工具箱”先搬出来让我用。
2. **`print("Hello, World!")`**：
   * `print` 意为“打印”。
   * 括号 `()` 里面是要打印的原料。
   * 双引号 `""` 圈起来的部分代表“**原始文本流**”（String 字符串）。
   * **大白话**：在屏幕底部的“控制台（Console）”黑板报上，原封不动地写下 `Hello, World!` 这行字。

---

### 3.2 变量与常量的声明与修改

在 Swift 中，只要你想在电脑内存里存一个数据，就必须“声明一个箱子”。

```swift
// ==================== 1. 常量 (锁死的保险箱let) ====================
let speedLimit = 120 // 声明 speedLimit 是个锁死箱，存入数字 120
// speedLimit = 100 // ❌ 这一行如果取消注释会报错！因为 let 箱子一旦锁死，绝不允许修改

// ==================== 2. 变量 (可变的抽屉var) ====================
var currentScore = 10 // 声明 currentScore 是个可变抽屉，放入初始值 10
currentScore = 25     // 重新拉开抽屉，把旧的 10 扔了，放入新数字 25

// ==================== 3. 箱子之间的数据拷贝 ====================
let baseValue = 50       // 声明锁死箱 baseValue，装入 50
var calculatedValue = 0  // 声明抽屉 calculatedValue，装入初始值 0

calculatedValue = baseValue // 拉开 calculatedValue 抽屉，把里面的 0 扔掉；复制一份 baseValue 里的 50 放入其中。
```

#### 🔍 语法符号解剖：
* **`let` 关键字**：
  * **大白话**：告诉电脑：“*我要定下一个**常量（锁死的保险箱）**，以后谁也别想改它的值！*”
* **`var` 关键字**：
  * **大白话**：告诉电脑：“*我要声明一个**变量（可变抽屉）**，里面的数据在 App 运行中会经常变化。*”
* **等号 `=`**：
  * **注意**：在编程里，单一等号 `=` **不是数学上的“等于”**！
  * **大白话**：等号表示**“赋值/放入”**。意思是把等号**右边**的东西，拷贝并塞进等号**左边**的箱子里。
* **双斜线 `//` 与 `/* */`**：
  * **大白话**：这是**注释**。写给人类看的便利贴。电脑在看到这些符号时会自动跳过去，绝不执行它们。

## 💡 4. 新手容易踩的两个坑 (Pitfalls)

1. **命名开头不能是数字**：
   * `let a1 = 10` （✅ 允许）
   * `let 1a = 10` （❌ 电脑报错。因为电脑在读取代码时，如果以数字开头，会误以为这是个具体的数值，而不是箱子名字，导致逻辑打架）。
2. **二次赋值时不要重复写 `var`**：
   * 第一次声明抽屉：`var score = 10` （✅ 必须写 var 告诉电脑新建抽屉）
   * 改变抽屉的值：`score = 25` （✅ 直接写名字赋值）
   * 错误写法：`var score = 25` （❌ 电脑会报错：提示你已经造过一个叫 score 的抽屉了，不能重复建造）。
