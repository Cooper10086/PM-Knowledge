# 25. 按钮创建与事件绑定 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：看懂 UIButton 的继承层级与核心状态机，掌握按钮在不同状态（正常、按压、禁用）下装载文案和图片的 API，并彻底理清经典交互模式——“目标-动作绑定 (Target-Action)”的底层逻辑。

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **`UIButton`** | “写个 Button 交互” | **“可触发交互控制键”**。继承自 `UIControl` 基类。专门用来接收用户的触碰，并在各种状态切换下派发事件的 UI 控件。 |
| **`ButtonType`** | “把 ButtonType 设为 custom” | **“出厂外形流派”**。按钮初始形态。`.custom` 代表素白素面，没有任何系统自带样式（商业项目最爱，方便全面定制设计图）；`.system` 代表系统默认蓝字。 |

| **Target - Action** | “绑定 Target 和 Action” | **“拉一根物理导线插在指令盒上”**。事件映射关系。`Target` 代表指令下发去哪里执行（通常是当前的 UIViewController 页面）；`Action` 代表具体要跑的那个函数方法名。 |
| **`#selector`** | “用 selector 指明方法” | **“指令方法贴纸名”**。在 Swift 中用来代表目标 Action 方法的名字。必须用 `@objc` 声明，因为要兼容苹果底层的 OC 运行期派发系统。 |
| **`.touchUpInside`** | “事件选 touchUpInside” | **“框内安全释放点击”**。最常用的事件类型。只有用户在按钮框内按下，且手指在按钮框内抬起时，才触发动作。**允许用户在按住时把手滑出去反悔**。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 搞懂 UIButton 的继承树与 UIControl 作用
* **继承关系**：`UIButton` -> `UIControl` -> `UIView` -> `UIResponder` -> `NSObject`。
* **物理分工**：`UIView` 只负责“被看见和定位大小”；而 `UIControl` 则在其上封装了“点击、状态切换、派发事件”的控制属性。因此，`UIButton` 天生自带了这些控制基因。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 基于状态机的内容装载

```swift
// 1. 类工厂模式初始化一个空白素胚按钮 customBtn
let customBtn = UIButton(type: .custom)

// 2. 🚨 核心：必须使用 setTitle(_:for:)，绝对不能用 titleLabel.text 赋值！
customBtn.setTitle("提交订单", for: .normal)      // 正常态显示
customBtn.setTitle("处理中...", for: .highlighted) // 指针按住未松开时显示
customBtn.setTitle("订单已锁", for: .disabled)    // isEnabled 关掉时显示

// 3. 修改字体大小（通过 titleLabel 可选属性进行修改）
customBtn.titleLabel?.font = UIFont.systemFont(ofSize: 18, weight: .semibold)

// 4. 为正常态装载一个背景底图
customBtn.setBackgroundImage(UIImage(named: "btn_blue_bg"), for: .normal)
```

#### 🔍 语法细节解剖：
* **`setTitle("提交订单", for: .normal)`**：
  * **`for: .normal`**：
  * **大白话**：告诉系统：“*只有在按钮状态处于 `normal`（默认正常状态）下，才在按钮上渲染出‘提交订单’这四个字。*” 如果在别的状态（比如高亮），不显示这个词。
* **`customBtn.titleLabel?.font`**：
  * **问号 `?` 可选链**：因为 UIButton 内部可能会没有文本框（比如纯图片按钮），所以 `titleLabel` 是可选值。修改字体时必须加上 `?` 以防没有文本框时崩溃。

### 3.2 目标-动作绑定 (Target-Action) 事件驱动

```swift
class OrderViewController: UIViewController {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        let payButton = UIButton(type: .custom)
        payButton.frame = CGRect(x: 100, y: 300, width: 200, height: 50)
        payButton.setTitle("立即支付", for: .normal)
        payButton.backgroundColor = UIColor.systemBlue
        
        // 💡 核心：拉线绑定点击事件！
        payButton.addTarget(self, action: #selector(handlePayment), for: .touchUpInside)
        
        self.view.addSubview(payButton)
    }
    
    // 🚨 动作函数：必须加上 @objc，暴露给底层 OC 动态派发系统
    @objc private func handlePayment() {
        print("订单支付成功！")
    }
}
```

#### 🔍 语法细节解剖：
* **`addTarget(self, action: #selector(handlePayment), for: .touchUpInside)`**：
  * **`self`**：代表 Target（接收命令的人），即当前的页面 `OrderViewController`。
  * **`action: #selector(handlePayment)`**：代表要执行的动作名字，即下面写好的 `handlePayment` 方法。
  * **`for: .touchUpInside`**：代表触发事件。手指在按钮内部松开时，才将电信号传过去运行。
* **`@objc private func handlePayment()`**：
  * **`@objc` 修饰符**：告诉 Swift，请在这个方法头部标注，允许苹果底层的 Objective-C 运行期消息派发系统能够顺利找到它，否则点击按钮时，程序会直接因“找不到方法”而闪退。
