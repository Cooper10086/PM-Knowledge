# 03. 基本数据类型 (iOS 基础教程 - PM 零基础精讲版)

> **本章学习目标**：看懂 Swift 语言中最核心的 4 种基础数据箱（整数、小数、文本、开关），并理解为什么乱塞数据会导致 App 闪退。

---

## 📖 1. 本章名词字典 (Glossary for PM)

| 英文技术名词 | 研发口头禅 | 大白话通俗解释 (PM Metaphor) |
| :--- | :--- | :--- |
| **Bit / Byte** | “比特与字节” | **“最小发光单元与标准柜”**。Bit 是二进制里存 0 或 1 的最小单位。1 字节 (Byte) = 8 比特 (Bit)。手机内存容量就是由无数个字节拼起来的。 |
| **Int** | “声明一个 Int 整数” | **“普通整数箱”**。专门用来装没有小数点数值的盒子（如 100、-5、0）。在 64 位手机上，它的容量极大，足够记录几亿亿的数字。 |
| **Int8 / UInt8** | “限宽整型” | **“迷你小抽屉”**。只占 1 个字节（8位）的超小整数盒。`Int8` 范围为 -128 到 127；带有 `U` 前缀代表无符号，不能装负数，`UInt8` 范围为 0 到 255。 |
| **Double / Float** | “用浮点数存小数” | **“高精度秤与普通秤”**。`Double` 是双精度小数盒，能精准保留到小数点后 15 位；`Float` 是单精度，只能保留到后 6 位。 |
| **Bool** | “布尔值” | **“开关/闸门”**。极其省空间。只有两个状态的特殊类型：`true` (真 / 开启) 和 `false` (假 / 关闭)。 |
| **Type Annotation** | “显式类型标注” | **“给箱子贴上强力分类标签”**。在变量名后加上冒号和类型名（如 `: Int`），强制规定这个箱子只能装什么，不能混装。 |
| **Literal Value** | “字面量” | **“未装箱的原始数据”**。在代码中直接写出的具体字面数值或文字（如直接写 `100` 或 `"Hello"`）。 |

## 🧭 2. 教程步骤逐步拆解 (Step-by-Step Breakdown)

### 2.1 计算机存储的基础知识
* **教程说**：位 (Bit) 和字节 (Byte) 换算公式为 $1 \text{ Byte} = 8 \text{ Bits}$。
* **大白话翻译**：计算机底层只认识 `0` 和 `1`。1 个 Bit 就像是 1 个只能亮或灭的灯泡。8 个灯泡组合起来（即 1 字节 Byte），就可以通过亮灭的不同排列，表达出 $2^8 = 256$ 种不同的状态。因此，1 个 Byte 可以安全地存储 $0 \sim 255$ 之间的任何一个数字。

## 💻 3. 代码逐句大白话解剖 (Line-by-Line Code Breakdown)

### 3.1 查看数据箱的极限范围与溢出崩溃

```swift
print("Int8 最小值: \(Int8.min)") // 1. 打印 Int8 能装的最小值：-128
print("Int8 最大值: \(Int8.max)") // 2. 打印 Int8 能装的最大值：127

// var age: Int8 = 200 // ❌ 这一行代码会直接报错崩溃！
```

#### 🔍 逐句解剖：
1. **`print("Int8 最小值: \(Int8.min)")`**：
   * 在双引号字符串中，**`\(表达式)`** 是一种叫做**“字符串插值”**的语法。
   * **大白话**：告诉电脑，请把括号里的 `Int8.min`（即 Int8 的最小值属性）算出来，塞进这段话里打印到黑板报上。最后输出：`Int8 最小值: -128`。
2. **`var age: Int8 = 200`**：
   * 声明一个名为 `age` 的 `Int8` 迷你整数箱，并强行塞入数字 `200`。
   * **为什么崩溃**：因为 `Int8` 盒子的盖子尺寸上限是 `127`。硬往里塞 `200` 就会发生**溢出崩溃 (Overflow)**。编译器会卡死报错，拒绝把程序打包上架。

### 3.2 显式类型标注与隐式推断

```swift
// 1. 显式类型标注：指明要什么箱子
var userScore: Int = 100
let piValue: Double = 3.14159

// 2. 隐式类型推断：让电脑自己猜箱子
var count = 100    // 电脑自动推断 count 是 Int 类型
let average = 87.5 // 电脑自动推断 average 是 Double 类型
```

#### 🔍 语法细节解剖：
* **`var userScore: Int = 100`**：
  * `: Int` 就是**显式标注**。
  * **大白话**：告诉电脑：“*给我造一个名叫 `userScore` 且挂着 `Int` 标签的箱子，然后把 `100` 放入其中。*” 哪怕后续放入其他整数，箱子标签也改不了。
* **`let average = 87.5`**：
  * 没有写冒号和类型。
  * **注意**：Swift 看到 `87.5` 带小数点，**默认会自动推断为 Double（高精度浮点）类型**，而不是 Float。

### 3.3 浮点数精确度对比

```swift
var floatValue: Float = 2.333333333333   // 1. 单精度小数箱
var doubleValue: Double = 2.333333333333 // 2. 双精度小数箱

print("Float 输出: \(floatValue)")   // 输出: 2.333333 (丢弃了后半部分)
print("Double 输出: \(doubleValue)") // 输出: 2.333333333333 (完美保留)
```

#### 🔍 逐句解剖：
* **`var floatValue: Float = ...`**：
  * 因为指定了 `Float` 类型，它的内存只有 4 字节，最多只能记住小数点后 6 位。后面的 `3` 会被无情抛弃，导致**精度丢失**。
* **`var doubleValue: Double = ...`**：
  * 指定了 `Double`，内存有 8 字节，能精准记住后 15 位。因此能完美输出。苹果系统框架默认一律使用 `Double`。

### 3.4 布尔型 (Bool) 的开关逻辑控制

```swift
var isBluetoothOn: Bool = false // 1. 声明蓝牙开关状态为：关闭 (false)
isBluetoothOn = true            // 2. 重新赋值为：开启 (true)

if isBluetoothOn { // 3. 如果蓝牙是开启的
    print("扫描设备")
}

var isUserLoggedIn: Bool = false
isUserLoggedIn.toggle() // 4. toggle() 表示“快速拉闸取反”
// 此时 isUserLoggedIn 的值由 false 自动反转为 true
```

#### 🔍 逐句解剖：
* **`if isBluetoothOn`**：
  * **大白话**：`if` 意为“如果”。如果 `isBluetoothOn` 这个箱子里存的是 `true`，就去执行大括号 `{}` 里的 `print`。
* **`isUserLoggedIn.toggle()`**：
  * **`.toggle()`** 是布尔值箱子独有的**“拉闸”方法**。
  * **大白话**：不需要手动写 `=` 重新赋值。如果箱子里原本是 `false`，执行一次 `toggle()` 就会瞬间反转成 `true`；反之亦然。通常用来控制点击按钮时红点/开关的亮起和熄灭。
