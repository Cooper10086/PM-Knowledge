# 08.数组基本使用-实战教程

在 Swift 中，高效地组织和管理数据集合是实现业务逻辑的基础。除了常规的条件分支流，Swift 还提供了**三目条件运算符**以简化二选一的赋值逻辑；同时，**数组（Array）**作为最基础的有序集合类型，是承载同构数据队列的核心载体。

本教程将深入解析三目条件运算符的工程适用场景，并全面拆解 Swift 数组的声明、初始化、动态增删改查及内存平移补位原理。

---

## 🎛️ 三目条件运算符 (Ternary Conditional Operator)

三目条件运算符是 `if-else` 条件分支的紧凑单行形式，旨在将二选一的赋值逻辑精简为表达式。

### 1. 语法结构与解析
```swift
// 结构公式
条件 ? 表达式1 : 表达式2
```
- **执行过程**：系统首先计算 `条件`（必须是 `Bool` 值）。
  - 若条件为 `true`，则计算并返回 `表达式1` 的结果；
  - 若条件为 `false`，则计算并返回 `表达式2` 的结果。

### 2. 代码实战对比
若我们需要根据用户的年龄来判定其是否符合成年标准，并赋予不同的标签：
```swift
let userAge = 19

// 💡 方案 A: 使用三目条件运算符（推荐，仅需 1 行）
let ageLabel = userAge >= 18 ? "已成年" : "未成年"

// ❌ 方案 B: 使用传统 if-else 语句（较为冗长，需 7 行）
let ageLabelAlternative: String
if userAge >= 18 {
    ageLabelAlternative = "已成年"
} else {
    ageLabelAlternative = "未成年"
}
```

> ⚠️ **工程规范约束**：
> 三目运算符仅适用于**简单的二选一值传递或赋值**场景。若在“值1”或“值2”处嵌套更深层的三目运算符（如 `a ? b : c ? d : e`），会严重破坏代码可读性。在多分支或复杂逻辑块执行时，必须回归使用标准的 `if-else` 或 `switch` 语句。

## 📦 Swift 数组 (Array) 底层逻辑与构建

数组是用于存放**相同类型**数据的**有序**集合。Swift 的数组在内存中是连续分配的，因此支持极高速度的随机访问。

### 1. 数组类型声明与空初始化
在 Swift 中，数组的声明方式非常严格，要求所有成员的类型必须完全一致。声明空数组时，我们通常使用以下两种等价写法：

```swift
// 写法 A：显式标注类型（左侧声明 [String] 数组类型，右侧赋空数组字面量）
var shoppingList: [String] = []

// 写法 B：类型推断形式（左侧依靠右侧的初始化器实例化 [String] 类型）
var shoppingListAlternative = [String]()
```

### 2. 带默认值的数组初始化
```swift
// 系统会自动推断 heroes 的类型为 [String]
var heroes = ["李逍遥", "赵灵儿", "林月如", "王小虎"]
```

## 🔄 数组元素动态操作 (增、删、改、查)

### 1. 增 (Append & Insert)
- **`.append(_:)`**：在当前数组的**末尾**追加一个新元素。时间复杂度为 $O(1)$。
- **`.insert(_:at:)`**：在指定的索引（Index）处插入一个元素，原本该位置及后面的元素将自动往后移动一位。时间复杂度为 $O(n)$。

```swift
var team = ["李逍遥", "赵灵儿"]

team.append("林月如") // 此时 team 为 ["李逍遥", "赵灵儿", "林月如"]
team.insert("酒剑仙", at: 1) // 此时 team 为 ["李逍遥", "酒剑仙", "赵灵儿", "林月如"]
```

### 2. 查 (Accessing Elements)
数组下标（索引）**严格从 0 开始**，最大索引值为 `count - 1`。
```swift
let firstHero = team[0] // 取得 "李逍遥"
let secondHero = team[1] // 取得 "酒剑仙"
```
> 🔴 **运行时陷阱 (Out of Bounds)**：如果访问的索引超出范围（例如 `team[10]`），程序会在运行时直接崩溃，报错 `Index out of range`。在读取前，务必保证索引值小于 `team.count`。

### 3. 改 (Modifying Elements)
直接通过下标操作符在等号左侧进行赋值：
```swift
team[1] = "阿奴" // 将原 1 号索引处的 "酒剑仙" 修改为 "阿奴"
// 此时 team 为 ["李逍遥", "阿奴", "赵灵儿", "林月如"]
```

### 4. 删 (Removing Elements)
- **`.remove(at:)`**：删除指定索引的元素。
- **`.removeFirst()`**：删除首位元素（索引 0）。
- **`.removeLast()`**：删除末尾元素（索引 `count - 1`）。
- **`.removeAll()`**：彻底清空数组，释放内存。

## 📌 数组删除元素后的“平移补位”原理解析

在数组中，当中间的某一项元素被删除后，**其后方的所有元素在物理内存中的索引会自动向前递补平移**。这是为了保证数组在内存中的连续性和有序性。

### 示图对比：执行 `team.remove(at: 1)`

#### 1. 执行前状态（此时 1 号为 "阿奴"）：

| 索引位置 | 0 | 1 (删除目标) | 2 | 3 |
| :--- | :--- | :--- | :--- | :--- |
| **元素内容** | "李逍遥" | **"阿奴"** | "赵灵儿" | "林月如" |

#### 2. 执行后状态（1 号阿奴被移除，后续元素前移）：

| 索引位置 | 0 | 1 (原2号前移) | 2 (原3号前移) |
| :--- | :--- | :--- | :--- |
| **元素内容** | "李逍遥" | **"赵灵儿"** | **"林月如"** |

```swift
var team = ["李逍遥", "阿奴", "赵灵儿", "林月如"]
team.remove(at: 1) // 移除 "阿奴"

print(team[1]) // 输出: "赵灵儿"（原本的 2 号前移至 1 号）
print(team.count) // 输出: 3
```

## 🏁 综合实战演练代码块

建议在 Xcode Playground 中运行并体会数组与三目条件运算符的协作：

```swift
import Foundation

// 1. 实战：使用数组管理购物车
var cart: [String] = ["MacBook Pro", "iPad Air"]

// 动态追加商品
cart.append("iPhone 15")
cart.append("Apple Watch")

// 用户移除不需要的商品（iPad Air 在 1 号索引）
cart.remove(at: 1) 

// 2. 实战：数组状态判定与三目运算符联动
// 如果购物车不为空，提示结算商品数；如果为空，提示购物车空空如也。
let cartStatusMessage = !cart.isEmpty ? "您当前有 \(cart.count) 件商品等待结算" : "购物车是空的"
print(cartStatusMessage) // 输出: "您当前有 3 件商品等待结算"

// 打印购物车最终列表
print("购物车清单:")
for item in cart {
    print("- \(item)")
}
```
